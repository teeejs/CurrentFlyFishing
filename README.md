# CurrentFlyFishing (retired)

The privacy policy, terms of use and support pages for the Current app now
live at https://currentfishing.com/privacy.html, /terms.html and
/support.html (source: the `current-fishing-website` repo).

The pages here only redirect there, so old links keep working. Before
archiving this repo or disabling GitHub Pages, confirm that App Store
Connect's Privacy Policy URL and Support URL point at currentfishing.com.
